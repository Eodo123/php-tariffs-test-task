# PHP Tariffs Test Task

Тестовое задание на разработку приложения для управления тарифами.

## Возможности

- просмотр списка тарифов;
- создание тарифа;
- просмотр тарифа;
- редактирование тарифа;
- изменение скорости тарифа через AJAX;
- экспорт тарифов в CSV;
- импорт тарифов из CSV;
- проверка данных при импорте CSV;
- экспорт списка тарифов в PDF.

 ## Локальный запуск

### Требования

- PHP 8.4+
- Composer
- SQLite

### Установка

Клонируйте репозиторий:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd php-tariffs-test-task

composer install

touch database/database.sqlite
php src/database/migrate.php
